\subsection{Overview}

This section describes the systematic approach for developing and evaluating machine learning models for Bitcoin price prediction. The methodology encompasses data collection, feature engineering, model selection, training, evaluation, and orchestration.

\noindent
\textbf{Key Details:}
\begin{itemize}
    \item \textbf{Data Collection:} CoinGecko API + hourly GitHub Actions updates
    \item \textbf{Preprocessing:} Validation, imputation, outlier removal
    \item \textbf{Feature Engineering:} 24 technical indicators, StandardScaler normalization
    \item \textbf{Train/Test Split:} 334 samples (80\%) training, 30 samples (20\%) test
    \item \textbf{Model Training:} 6 ensemble, 4 deep learning, 1 time-series (11 total)
    \item \textbf{Evaluation:} Accuracy, F1, RMSE, R² metrics
    \item \textbf{Selection:} Best by classification/regression metrics
    \item \textbf{Deployment:} Google Cloud Storage + Vertex AI Registry
\end{itemize}

\subsection{Data Collection}

\textbf{Source:} CoinGecko API (free, no authentication required)
\begin{itemize}
    \item Historical data: 365+ days of daily OHLCV (Open, High, Low, Close, Volume)
    \item Hourly updates via GitHub Actions (automated pipeline)
    \item Latest data always available for real-time predictions
\end{itemize}

\subsection{Data Preprocessing}

\begin{itemize}
    \item \textbf{Missing Values:} Forward-fill imputation (preserves temporal continuity)
    \item \textbf{Outliers:} IQR-based detection and removal
    \item \textbf{Validation:} Schema and range validation
    \item \textbf{Temporal Ordering:} Ensure chronological ordering for time-series integrity
\end{itemize}

\subsection{Feature Engineering}

\textbf{24 Technical Indicators:}
\begin{itemize}
    \item \textbf{Trend Indicators:} SMA(7, 14, 30), EMA(7, 14)
    \item \textbf{Momentum Indicators:} RSI(14), MACD, Rate of Change
    \item \textbf{Volatility Indicators:} Bollinger Bands, Standard Deviation
    \item \textbf{Volume Indicators:} Volume SMA, Volume Change Ratio
    \item \textbf{Price Ratios:} Price relative to moving averages
\end{itemize}

\textbf{Normalization:} StandardScaler (zero mean, unit variance)

\subsection{Train/Test Split}

\textbf{Strategy:} Temporal split (prevents future data leakage)
\begin{itemize}
    \item \textbf{Training Set:} 335 samples (80\%)
    \item \textbf{Test Set:} 30 samples (20\%)
    \item \textbf{No Shuffling:} Maintains temporal order
    \item \textbf{No Overlap:} Training ends before test begins
\end{itemize}

\subsection{Models Tested (11 Total)}

\subsubsection{Ensemble Models (3)}
\begin{itemize}
    \item \textbf{RandomForest:} n\_estimators=300, max\_depth=12
    \item \textbf{GradientBoosting:} n\_estimators=300, learning\_rate=0.05
    \item \textbf{XGBoost:} n\_estimators=500, learning\_rate=0.05
\end{itemize}

\subsubsection{Deep Learning Models (4)}
\begin{itemize}
    \item \textbf{LSTM Classifier \& Regressor:} 2 layers (64→32 units), Dropout(0.2)
    \item \textbf{GRU Classifier \& Regressor:} 2 layers (64→32 units), Dropout(0.2)
    \item \textbf{Sequence Length:} 7-day lookback window
    \item \textbf{Training:} 50 epochs, EarlyStopping (patience=10)
\end{itemize}

\subsubsection{Time-Series Model (1)}
\begin{itemize}
    \item \textbf{Prophet:} Seasonal decomposition with trend and weekly seasonality
\end{itemize}

\subsubsection{Classification vs. Regression}
\begin{itemize}
    \item \textbf{Classification (5 models):} Predict price direction (↑ Up / ↓ Down)
    \item \textbf{Regression (5 models):} Predict price change magnitude (\%)
    \item \textbf{Time-Series (1 model):} Multi-step forecasting
\end{itemize}

\subsection{Model Evaluation Metrics}

\textbf{Classification Metrics:}
\begin{itemize}
    \item \textbf{Accuracy:} Proportion of correct predictions
    \item \textbf{F1-Score:} Harmonic mean of precision and recall
    \item \textbf{Precision \& Recall:} True positive rate and positive predictive value
\end{itemize}

\textbf{Regression Metrics:}
\begin{itemize}
    \item \textbf{RMSE:} Root Mean Squared Error (penalizes large errors)
    \item \textbf{R² Score:} Coefficient of determination (variance explained)
    \item \textbf{MAE:} Mean Absolute Error (robust to outliers)
\end{itemize}

\subsection{Model Selection Strategy}

\begin{enumerate}
    \item Train all 11 models independently
    \item Evaluate each on test set using respective metrics
    \item For Classification: Select model with highest F1-Score
    \item For Regression: Select model with highest R² Score
    \item Version selected models with timestamp and metrics
    \item Store in model registry for deployment
\end{enumerate}

\subsection{Orchestration \& Automation}

\begin{itemize}
    \item \textbf{Daily Pipeline:} Prefect orchestration (Flows, Tasks, Retries)
    \item \textbf{Hourly Features:} GitHub Actions scheduled automation
    \item \textbf{Model Versioning:} JSON manifest with metadata and metrics
    \item \textbf{Cloud Deployment:} Google Cloud Storage + Vertex AI Model Registry
    \item \textbf{Notifications:} Discord alerts on success/failure
\end{itemize}

\subsection{Hyperparameter Tuning}

All hyperparameters were selected through:
\begin{itemize}
    \item Grid search over common ranges
    \item Early experimentation phase (non-production)
    \item Cross-validation on training data
    \item Final parameters frozen for production pipeline
\end{itemize}

\subsection{Summary}

The methodology follows industry-standard ML best practices: systematic data collection → preprocessing → feature engineering → temporal train/test split → model training on diverse architectures → rigorous evaluation → model selection → versioning → cloud deployment. This reproducible pipeline is automated via Prefect and GitHub Actions for continuous integration and retraining.
